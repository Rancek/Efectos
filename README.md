# ✨ Efectos Visuales y composición

Los efectos visuales permiten modificar, complementar o construir elementos que forman parte de una producción audiovisual.

Durante mi formación universitaria fui trabajando diferentes ejercicios para comprender cómo integrar estos elementos de manera coherente dentro de una escena.

El proceso general puede representarse como:

**Idea → Material original → Preparación → Efectos → Composición → Correcciones → Resultado final**

---

# 🎬 Composición digital

La composición es una parte fundamental dentro del proceso de VFX.

Permite combinar diferentes elementos visuales dentro de una misma escena buscando conseguir un resultado coherente.

Durante estos trabajos fui explorando aspectos como:

- 🖼️ Integración de elementos.
- 🎥 Trabajo con material audiovisual.
- ✨ Aplicación de efectos.
- 💡 Iluminación.
- 🌑 Luces y sombras.
- 🎨 Color.
- 🎭 Construcción visual de la escena.
- 🎞️ Presentación final.

---

# ⏱️ Timing de los efectos

El timing también cumple un papel importante dentro de los efectos visuales.

Un efecto debe aparecer, desarrollarse y finalizar de manera coherente con la acción presente en la escena.

Durante los diferentes ejercicios trabajé la relación entre:

**Acción → Inicio del efecto → Desarrollo → Impacto → Finalización**

Esto permite que el efecto acompañe correctamente el ritmo de la escena.

---

# 🎨 Integración visual

Otro de los objetivos trabajados durante mi formación fue conseguir que los diferentes elementos utilizados dentro de una composición mantuvieran una apariencia visual coherente.

Para ello se consideran aspectos como:

- 💡 Iluminación.
- 🌑 Sombras.
- 🎨 Color.
- 🔆 Intensidad.
- 🎥 Perspectiva.
- ✨ Apariencia del efecto.
- 🖼️ Composición general.

---

# 🎞️ Proceso de trabajo

Dependiendo del proyecto, el proceso utilizado para desarrollar los efectos siguió diferentes etapas:

### ✨ Efectos Visuales

**Idea → Referencias → Preparación → Creación del efecto → Integración → Refinamiento**

### 🎬 Composición

**Material original → Elementos → Composición → Iluminación → Color → Ajustes**

### 🎥 Postproducción

**Composición → Correcciones → Efectos → Edición → Revisión → Resultado final**
